## 📌 Sobre o projeto

Este projeto consiste em uma aplicação de lista de tarefas (To-Do List), desenvolvida em PHP, que permite ao usuário adicionar e remover tarefas de maneira simples e intuitiva.

O objetivo é praticar conceitos fundamentais de programação em PHP, manipulação de formulários HTML e gerenciamento de dados utilizando sessões.

---

## ⚙️ Funcionalidades

- ➕ **Adicionar tarefas:** permite cadastrar novas tarefas.
- 🗑️ **Remover tarefas:** permite excluir tarefas da lista.
- 📋 **Listar tarefas:** exibe as tarefas adicionadas.
- 💾 **Armazenamento em sessão:** mantém as tarefas durante a sessão do usuário.
- ✅ **Validação de entrada:** impede o cadastro de tarefas vazias.
- 📱 **Interface simples:** layout com HTML e CSS.

## 🚀 Como executar o projeto

### Pré-requisitos

- PHP instalado no computador.

### 1. Clone o repositório

```bash
git clone https://github.com/M0rguinha/todo-php.git
```

### 2. Entre na pasta do projeto

```bash
cd todo-php
```

### 3. Inicie o servidor PHP

```bash
php -S localhost:8000
```

### 4. Acesse no navegador

Abra o endereço:

http://localhost:8000
